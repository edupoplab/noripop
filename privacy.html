놀이팝 개인정보 처리방침

최종 수정: 2026년 10월 18일 · 현재 서비스의 처리 안내입니다. 정식 출시 전 국외 이전·제공업체 보유 조건의 추가 확인이 진행 중입니다.

🍿 놀이팝은 교사가 반과 놀이를 관리하는 서비스입니다. 유아 개인 계정이나 유아 이름·생년월일을 입력받는 가입 절차는 없습니다. 태블릿은 반 연결 정보로 동작합니다. 외부 놀이의 카메라·마이크 사용과 접속 정보 처리는 아래 안내를 확인해 주세요.

교사 PIN 원문 대신 검증용 해시를 앱에 저장합니다. PIN 복구 시 입력한 교사 이메일·비밀번호는 HTTPS로 로그인 서버에 전송하며, 복구 비밀번호를 앱 설정에 저장하지 않습니다. 복구용 반이 사전에 등록되어 있어야 해당 반 소유자 확인을 통한 재설정이 가능합니다.

Android 앱 하단의 “개인정보”에서 앱에 포함된 방침을 인터넷 연결 없이 읽을 수 있습니다. 안내 화면 자체는 네트워크·카메라·마이크·파일에 접근하지 않으며 외부 페이지로 이동하지 않습니다. 앱에 포함된 문서는 해당 앱 빌드 시점의 내용입니다.

2. 보유 기간

계정과 서비스 정보는 서비스 제공 기간 동안 처리합니다. 회원 탈퇴를 요청하면 본인이 놀이팝에 직접 올린 사진·썸네일을 먼저 삭제하고, 남은 파일이 없는지 확인한 뒤 로그인 계정 및 연결된 프로필·모음·등록 놀이·저장·적립·문의 자료를 삭제합니다. 다른 선생님이 저장한 내 놀이에도 영향을 줄 수 있습니다. 시험 결제 주문·시험 이용권 기록은 함께 삭제하며, 사용한 이용권 코드는 재사용 방지를 위해 사용 표시만 남기고 회원 계정 연결을 해제합니다. 가격이나 기존 이용기간을 변경하는 절차는 아닙니다.

파일 삭제는 되돌릴 수 없으며, 도중에 실패해도 이미 삭제된 파일은 복원되지 않습니다. 일부 파일이나 계정 삭제가 확인되지 않으면 완료로 안내하지 않습니다. 다시 로그인해 상태를 확인하거나 이메일로 문의해 주세요. 외부 사이트·기기에 저장한 자료, 다른 사람이 별도로 복사한 자료와 브라우저·CDN 캐시는 이 절차로 모두 즉시 삭제된다고 보장하지 않습니다. 실제 결제·문자 인증은 현재 제공하지 않으며, 도입 전에 수집 항목과 별도 보유 조건을 고지합니다.

앱 삭제만으로 서버의 회원 계정이 탈퇴되지는 않습니다. 반 연결 해제는 현재 화면의 반 연결을 해제하며, 기기의 교사 PIN과 복구 정보까지 초기화하지는 않습니다. 기기 내 저장 정보는 Android 설정에서 놀이팝 앱 데이터를 삭제하거나 앱을 제거하여 지울 수 있습니다.

현재 확인된 Supabase Free 플랜의 조회 가능 범위는 API·데이터베이스 로그 1일, 인증 감사 로그 1시간입니다. 이는 제공업체 내부의 모든 기록이 같은 시점에 삭제된다는 뜻이 아닙니다. 이 프로젝트의 Free 플랜에는 제공업체 관리형 데이터베이스 백업이 제공되지 않습니다. 업체 내부 보안·지원 기록의 정확한 보유 조건은 추가 확인 중이며, 해당 기록까지 탈퇴 즉시 삭제된다고 안내하지 않습니다.

4. 제3자 제공

닉네임과 레벨은 공개 콘텐츠에 함께 표시됩니다. 이메일은 공개 라이브러리에 표시하지 않습니다. 업로드된 대표 이미지·활동 사진은 공개 URL로 제공되므로, 유아의 얼굴·이름·연락처 등 개인정보가 포함된 자료를 올리지 마세요.

5. 외부 놀이와 앱 권한

놀이를 실행하면 해당 놀이 운영자의 서버로 접속합니다. 놀이에 따라 카메라 영상, 마이크 음성, 입력한 정보 등이 처리될 수 있으며 실제 저장·전송 여부는 해당 놀이의 구현과 안내에 따라 달라집니다. 내부 실행창으로 열어도 외부 서비스와의 통신이 없어지는 것은 아닙니다. 교사는 유아에게 제공하기 전에 해당 놀이의 개인정보 안내와 권한 사용 목적을 확인해야 합니다.

  • 카메라·마이크: 해당 기능을 요청하는 놀이를 사용할 때 Android 권한을 요청합니다. 거절하면 해당 기능이 제한될 수 있습니다. Android 설정 → 앱 → 놀이팝 → 권한에서 변경할 수 있습니다.
  • 카메라·마이크 안내와 교사 PIN 확인은 설치한 앱 버전에 따라 다를 수 있습니다. 새 시험 버전에는 사이트별 자료 처리 안내와 허용/거절 선택이 포함되어 있으며, 정식 배포 전 기기 확인이 필요합니다. Android 권한 허용 자체는 외부 놀이의 자료 저장·전송에 대한 동의를 뜻하지 않습니다.
  • 파일 선택·다운로드: 교사가 선택한 파일을 놀이에 제공하거나, 놀이 결과물을 기기에 저장할 때 사용합니다. 구형 Android에서는 다운로드를 위한 저장소 권한을 요청할 수 있습니다.
  • 놀이팝 앱 자체가 카메라·마이크 자료를 서버로 업로드하는 기능과 외부 놀이의 자료 처리는 구분됩니다. 외부 놀이 전체에 대해 영상·음성 미수집을 보장하지 않습니다.
  • 교사 PIN과 Android 권한 허용은 다른 목적의 자료 전송·공개 또는 법적으로 필요한 보호자 동의를 대신하지 않습니다. 외부 서비스라는 이유만으로 놀이팝의 관련 의무가 배제되는 것은 아닙니다.
